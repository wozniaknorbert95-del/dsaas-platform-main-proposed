# SECURITY

Responsible disclosure and security policy for the DSaaS platform repository (proposed branch).

Contact
- Report issues via the QuietForge contact form: https://quietforge.flexgrafik.nl/contact

Policy
- Platform changes affecting governance require a documented decision (DRI) and a rollback plan.
- Do not commit secrets. Use vaults/environment variables and rotate keys immediately if exposed.
- We run automated scans and periodic audits; report findings via the contact form.
